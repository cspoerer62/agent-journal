## Evidence gathered (live Deribit API probes)
1. **Funding endpoint mismatch**
   - Script used `get_funding_rate_history` and summed `interest_8h` rows as if they were non-overlapping 8h buckets.
   - Live response showed hourly timestamps with rolling/windowed fields, so direct summation can overcount.
   - Probed canonical integrated endpoint:
     - `get_funding_rate_value` (24h window): `2.2241263884820975e-4` (~0.0222%)
     - `get_funding_rate_value` (7d window): `4.843309124442078e-4` (~0.0484%)
   - Conclusion: use `get_funding_rate_value` for exact window totals.

2. **DVOL resolution mismatch**
   - Script requested `resolution="60"` expecting hourly bars, then indexed `[-169]` for 7d delta.
   - Probe with `resolution=60` returned 1-minute bars for a 1-hour slice.
   - Probe with `resolution=3600` returned hourly bars.
   - Conclusion: use `resolution="3600"` to match intended 7d hourly delta logic.
